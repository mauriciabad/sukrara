# Sukrara Aura — the Garmin watch face

Connect IQ watch face (Monkey C) for the round 390 × 390 AMOLED Garmin watches with Connect IQ's enhanced graphics
(the products in `manifest.xml`; the owner's is the Descent Mk3i 43 mm, `descentmk343mm`). The design is
[`contracts/watchface/aura/SPEC.md`](../../../contracts/watchface/aura/SPEC.md) with its reference implementation
[`tools/watchface/aura.js`](../../../tools/watchface/aura.js) (the code wins). One of Sukrara's Garmin apps: the
layout, the shared link and the builds of all three are in [`apps/garmin/README.md`](../README.md); setup, keys,
simulator and sideloading in [docs/DEVELOPMENT.md › Garmin](../../../docs/DEVELOPMENT.md).

## How it's built

| File | What it is |
|---|---|
| `source/AuraInput.mc` | **The input model**: everything the face draws from (the port of aura.js `opt(cfg)`, SPEC.md §3) |
| `source/AuraData.mc` | **The seam**: `AuraReading` (what Sukrara on the phone sent) and `AuraData.current()`, the one place the face reads it; `AuraData.reading(now)` fills it from the shared link |
| `source/AuraWatch.mc` | Fills the input model at every draw: the clock, mode, battery, fields' data, settings, and the seam's reading aged by the watch clock |
| `source/AuraModel.mc` | **The layout**: every value of the face, a pure function of the input (aura.js `renderVals()`) |
| `source/AuraDraw.mc` | Paints the model (every glyph from the fonts' atlases) |
| `source/AuraDial.mc` | **The aura** (SPEC.md §6.12): `AuraDial`, a dial's numbers and its painting; `AuraDials`, the dial's cached bitmap (painted again only when its inputs change) and the seconds sweep (§6.11) |
| `source/AuraHalo.mc` | The halo (§6.13): its numbers and the black cut-out over the dial |
| `source/AuraView.mc` | The face: every frame's model, the always-on shift and the glide on a new reading (§7) |
| `source/AuraWords.mc` | The drawn words, en / es (Sukrara's card words, `contracts/graph/words/words.json`) |
| `../shared/link/` | **The phone link** (docs/43, `contracts/watchface/payload`), shared with the other apps: `LinkService` (the background: Sukrara's push through Garmin Connect, the 5-minute fetch of `/sukrara/aura` from `127.0.0.1:17582`) and `Link` (keeps the newest payload in storage, works out the inputs at every draw) |
| `source/AuraSettings.mc` | The settings (Connect IQ properties) and the watch's Customize menu |
| `source/SettingsSpec.mc`, `resources/settings/` | Generated by `python3 tools/settings/gen.py` from `contracts/settings/settings.json` |
| `source-cases/`, `cases.jungle`, `manifest-cases.xml`, `tools/` | The debug case loader (every symbol `(:debug)`, its own app id) and its tools: `cases.py` (the cases into `build/cases`), `garmin_test.py` (words, numbers, pictures), `core_refs.mjs`, `fonts.py` |
| `test/`, `link-test.jungle` | The seam's test (`AuraSeamTest`), run with the shared link's tests by `apps/garmin/tools/link-test.sh aura` |
| `source/AuraFontTable.mc`, `resources/fonts/`, `resources/icons/` | Generated by `uv run apps/garmin/aura/tools/fonts.py` from Atkinson Hyperlegible Next (`apps/garmin/fonts/`, OFL): one 8-bit alpha atlas per font size, plus the icon paths of SPEC.md §2 |

## The seam (for the data link)

`AuraData.current()` returns the last `AuraReading` Sukrara on the phone sent, or `null` when there is none (the face
then says "No readings" and hides the level rail). It runs at every draw (1 Hz while awake), so keep it cheap: decode
the payload when it arrives, keep the `AuraReading`, return it here, and call `AuraData.changed()` so the face redraws.

Every time in `AuraReading` is absolute (epoch seconds, UTC): the face computes the age, the quiet / mute time left,
the time since the last treatment (and when it gives way), the warm-up and the sensor's hours itself at every draw, so it stays right between
messages and with the phone out of reach (late → old → no readings, from the reading's own time). The fields (see
`AuraData.mc` for each one's meaning) are Sukrara's decisions (ground rule 1): `rate` and `doubled` (the trend),
`status` / `statusUntil` (the pill: `auto` shows the need, `quiet` after a treatment, `muted`), `sensor`, `limits` (the
person's bands), `unit`. Unknown or missing values: leave the defaults (`rate` null = no trend, `history` null = no
trail).

The link fills it: `AuraData.reading(now)` (cached per second) turns the shared link's stored payload into the `AuraReading`, every
time moved onto the watch clock when the watch is behind the phone, the time-bound states worked out at `now` (a
quiet or mute that ran out shows no pill, the warm-up's *almost*, the sensor's *ending* / *ended*, ended but still
sending). `AuraApp` registers the background on every start and hands what it brings to `Link.take`.

## Commands

```sh
apps/garmin/build.sh aura          # release .prg (debug code compiled out) → apps/garmin/bin/SukraraAura.prg
apps/garmin/build.sh aura debug    # the face with debug code
apps/garmin/build.sh aura cases    # the debug case loader → bin/SukraraAura-cases.prg
apps/garmin/build.sh aura export   # the store package .iq (export-beta: under the beta app id); release: tools/release/garmin-release.sh aura
uv run apps/garmin/aura/tools/fonts.py    # regenerate fonts and icons (--check: up to date?)
python3 tools/settings/gen.py      # regenerate the settings after a schema change
apps/garmin/tools/link-test.sh aura   # the phone link's tests (contracts/watchface/payload) in the simulator
python3 apps/garmin/aura/tools/garmin_test.py words   # the drawn words against words.json
```
