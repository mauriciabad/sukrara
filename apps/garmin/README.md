# Sukrara on Garmin

Sukrara's Connect IQ apps (Monkey C), each its own app with its own id, store listing, phone push and 5-minute fetch
(the plan and the platform: [docs/47](../../docs/47-garmin-apps.md); the link: [docs/43](../../docs/43-garmin-link.md)).
Setup, keys, simulator and sideloading: [docs/DEVELOPMENT.md › Garmin](../../docs/DEVELOPMENT.md).

| Folder | What |
|---|---|
| [`aura/`](aura/README.md) | **Sukrara Aura**, the watch face (`watchface`) |
| `shared/` | What more than one app needs, compiled into each app that names it (below) |
| `tools/` | The tools every app uses: `link-test.sh`, `link_cases.py`, `verify_prg.sh`, `sideload.py`, `simshot.py` |
| `fonts/` | Atkinson Hyperlegible Next (OFL), the source of the atlases (`aura/tools/fonts.py`) |
| `build.sh` | The one build entry: `build.sh <app> [<mode>]` |

## Shared

`shared/` is one source tree, split by what an app uses, and each app's `monkey.jungle` names the folders it needs
(`base.sourcePath = source;../shared/link`): no barrel (docs/47 §2). A folder an app doesn't name never lands in its
build (the face's 128 KB are nearly full, #217). Where the apps differ inside a shared file (the fetch URL), the code
carries an annotation per app (`(:aura)`, `(:app)`, `(:field)`) and each jungle excludes the others'
(`base.excludeAnnotations`), so no app carries another's.

| Folder | What |
|---|---|
| `shared/link/` | **The phone link** (docs/43, `contracts/watchface/payload`): `LinkService` / `LinkBackground` (the background: Sukrara's push to the app's id through Garmin Connect, the 5-minute fetch from `127.0.0.1:17582`, the storage hand-off) and `Link` (the newest payload in storage, the order rule, the phone's clock lead, the run report the fetch carries, the inputs at every draw) |
| `shared/test/link/` | The link's tests (`LinkTest`, `LinkCases` generated by `tools/link_cases.py`), built into an app by its `link-test.jungle` |

## Commands

```sh
apps/garmin/build.sh aura [release]   # release .prg (debug code compiled out) → apps/garmin/bin/SukraraAura.prg
apps/garmin/build.sh aura debug       # with debug code → bin/SukraraAura-debug.prg
apps/garmin/build.sh aura export      # the store package (every product) → bin/SukraraAura.iq; export-beta: the beta id
apps/garmin/build.sh aura cases       # the face's debug case loader
apps/garmin/tools/link-test.sh aura   # the link's tests in the simulator (build: build only)
python3 apps/garmin/tools/link_cases.py   # regenerate shared/test/link/LinkCases.mc after cases.json changes
tools/install.sh watch                # every app onto the owner's watch (USB)
tools/release/garmin-release.sh aura <version>   # the store files, signed with the store key
```
