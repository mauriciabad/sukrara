# SukraraFace: changelog

Each release of SukraraFace (GitHub tag `face-sdk-v<version>`), newest first: `tools/release/release.py` writes each
entry from the [change files](../../../changes/README.md) that name it. Up to Sukrara 0.17.1 it went out with every
Sukrara release (as 5.0.0), in the shared [changelog](../../../CHANGELOG.md).
