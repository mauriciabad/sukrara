# Sukrara — brand assets

Generated by `python3 -I spikes/brand/brand.py export sukrara a` (investigation 09). Don't edit by hand:
change the concept in `brand.py` and re-export.

| Path | Use |
|---|---|
| `brand.json` | name, domain, application ids, brand + range colours, thresholds |
| `glyph.svg` | one-colour glyph (source for any small/mono use) |
| `macos/AppIcon.icns` | `CFBundleIconFile` of the .app (Big Sur grid, 1024 master in `AppIcon-1024.png` / `AppIcon.svg`) |
| `macos/dmg/Volume.icns`, `macos/dmg/DiskImage.icns` | the Mac disk image's own icons (`apps/macos/Bundle/dmg.sh`): the volume (a Sukrara drive, `.VolumeIcon.icns`) and the `.dmg` file (a disk image page with that drive); `*-512.png` previews. Not from `brand.py`: drawn by `swift assets/brand/sukrara/macos/dmg/icons.swift` (from the repo root) from `macos/AppIcon.svg`'s glyph; re-run after the app icon changes |
| `macos/MenubarGlyph*.png` | template image (black + alpha, set `isTemplate`) for menus / "no data yet" |
| `macos/Brand.swift` | name, URL, range colours as `NSColor` |
| `android/res/` | adaptive launcher icon with a monochrome layer (themed icons): copy into `app/src/main/res`, then `android:icon="@mipmap/ic_launcher"`; `drawable/ic_stat_sukrara.xml` is the notification small icon |
| `android/Brand.kt` | name, URL, brand + range colours for Compose |
| `android/play-store-512.png` | store / about-screen icon: full bleed, cropped to the 72 units launchers show. Not from `brand.py` (it renders the whole 108 canvas, glyph at 2/3 size): `python3 -I tools/brand/store_icons.py` renders it and `web/apple-touch-icon.png` from `brand.py`'s shapes |
| (Garmin) | Not from here: the Connect IQ launcher icons are drawn from `glyph.svg` by `uv run apps/garmin/tools/launcher_icons.py`, one per watch size |
| `connectiq/render.mjs` | Sukrara Aura's Connect IQ store icon (500 × 500), hero (1440 × 720, en / es) and screens (390 × 390), bezel-less from `tools/watchface` with synthetic cases → `docs/img/aura/store/ciq/`. Not from `brand.py`: `node assets/brand/sukrara/connectiq/render.mjs` (Chrome), again after the face changes |
| `web/` | `favicon.svg`, `favicon-32.png`, `apple-touch-icon.png`, `icon-512.png` (PWA manifest), `og.png` (link previews) |

Ids: application / bundle id `app.mauri.sukrara`.
